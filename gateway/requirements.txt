# Точні піни — див. пояснення в backend/requirements.txt: `==X.Y.*` не
# фіксує патч, тому образ можна було не відтворити. Значення — перевірені,
# не «останні доступні».

# `websockets` тут пряма залежність, а не «рахуємо разом із uvicorn»: gateway
# викликає `websockets.connect()` у релеї `/ws`, тож це наш код, а не деталь
# реалізації сервера. Раніше стояло `==12.*`, поки тести й локальне оточення
# підхоплювали 17.1 транзитивно — два середовища мовчки розійшлися, і жодне не
# перевіряло друге.
#
# Значення 17.1 перевірене: backend/tests/test_gateway_ws_relay.py піднімає
# справжній uvicorn і справжній релей через `websockets.connect` (5 тестів).
# Раніше релей не мав жодного тесту, тож «те, що реально працює» для нього
# було невідомим. Перевірено також на 12.0 — працює, але 17.1 це те, на чому
# проходять CI й 259 тестів, тож пін має називати саме цю версію.
