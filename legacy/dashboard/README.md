# Legacy dashboard

Стара статична сторінка, яка жила в `frontend/index.html` і монтувалася
бекендом на `/dashboard`. Це перша версія дашборду: одна HTML-сторінка з
інлайновими стилями, без збірки.

**Чому окремо, а не в `frontend/`:**

- `frontend/` — це Next.js-додаток (`src/app`, `next build`). Файл
  `index.html` у його корені нічого не робив для Next, але виглядав як
  частина застосунку й плутав при читанні репозиторію;
- бекенд монтував на `/dashboard` **теку** `frontend/`, а не сам файл. Тобто
  публічно (gateway не вимагає токен для `/dashboard`) віддавався весь каталог
  разом із `node_modules/`, `.env.example`, `next.config.mjs` і `.next/`.

Тепер монтується тільки цей каталог, а `/dashboard` віддає виключно
`index.html`.

**Коли видаляти:** щойно стане зрозуміло, що legacy-сторінка нікуди не
потрібна — наприклад, після того як усі сценарії зворотної сумісності
перейдуть на Next.js. Поки вона жива, `/dashboard` і окремий CSP для нього
у `gateway/headers.py` мають залишатися.
